# ANIMATION — Visual Generation Rules

## Purpose
Defines animation style, motion rules, visual consistency.

## Requirements
Soft rounded characters, gentle movement, warm lighting, pastel palette from BRAND.md, clear silhouettes, expressive facial animation, easy lip-sync, child-scale environments.

## AI Instructions
Reference before generating animation or image prompts. Maintain consistency.

## Best Practices
Reference `BRAND.md` and `CHARACTER.md` before generating animation prompts. Confirm soft, rounded motion curves. Confirm warm lighting consistency. Maintain merchandise-friendly appearance.
