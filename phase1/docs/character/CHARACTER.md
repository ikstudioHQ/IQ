# CHARACTER — Design Philosophy

## Purpose
Defines design philosophy for original characters. Actual designs belong to Phase 3.

## Design Principles
Extremely cute, original, memorable, soft rounded shapes, big expressive eyes, warm smiles, merchandise-friendly, easy to animate, easy to recognize, loved by children and parents, timeless, emotionally expressive.

## Personality Requirements (Future)
Every character: unique personality, speaking style, emotional traits, strengths, weaknesses, hobbies, relationships, educational role, Islamic values, growth arc.

## Visual Requirements
Large expressive eyes, rounded shapes, gentle smiles, soft palette, clear silhouettes, expressive emotions, easy facial animation, consistent proportions.

## Rules
Never imitate copyrighted characters. Design for merchandise and animation from the start.
