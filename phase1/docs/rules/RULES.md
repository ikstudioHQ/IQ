# RULES — Content & AI Generation Rules

## Purpose
Defines universal rules for all AI-generated content at Islamic Kids Studio.

## Overview
Universal rules for all AI-generated content.

## Design Principles
- Safe and parent-approved.
- Islamically respectful.
- Child-friendly and emotionally engaging.
- Educational, positive, and warm.

## Writing Rules
Write like an experienced human storyteller. Never sound like AI. Never repeat ideas. Never rewrite the same sentence differently. Never use unnecessary filler. Every sentence contributes. Conversational English. Short spoken sentences. Emotional storytelling. Show instead of tell. Consistent personalities. Avoid robotic transitions, keyword stuffing, generic phrases, repetitive dialogue, over-explaining. Write for ages 2–8 while engaging parents.

## Content Rules
Safe, parent-approved, Islamically respectful, child-friendly, emotionally engaging, educational, positive, warm.

## AI Rules
Load MASTER.md first. Load BRAND.md second. Load relevant domain docs. Validate output against RULES.md. Never skip validation.

## Best Practices
Always reference `MASTER.md` and `BRAND.md` before applying rules. Confirm all content passes validation against these rules before generation. Update rules when new series or formats launch.

## Future Expansion
Rules will expand with multi-language generation rules, parent content rules, and merchandise content rules.
