# ADR_001 — Character System: Zayd/Amira Cast Retained, Nur/Lumi Cast Retired

**Status:** accepted
**Date:** 2026-07-30

## Problem
The repository contained two complete, incompatible character systems
describing the show's cast: `phase2/`/`phase3/knowledge/characters/`
described Nur, Lumi, Mama, Baba, Bear; `sources/characters/` described
Zayd, Amira, Dada Yusuf, Baba Ahmad, Ummi Layla, Nuri, with locked
Pixar-style visual description blocks. `MASTER_PROMPT.md`'s Character
Module Orchestration section instructed loading both simultaneously as if
they described the same characters. An audit simulation confirmed this
broke the pipeline's character-continuity check (Step 12) for the
repository's own next scheduled episode.

## Decision
The Zayd/Amira/Dada Yusuf/Baba Ahmad/Ummi Layla/Nuri cast is the sole
canonical character system, repository-wide. The Nur/Lumi/Mama/Bear
system was retired: every file that referenced it (`knowledge_characters.json`,
`active_characters.json`, `character_versions.json`,
`character_relationships.json`, `character_version_lock.md`,
`knowledge_world.json`, `knowledge_story.json`, `knowledge_curriculum.json`,
`asset_registry.json`, `pronunciation_dictionary.json`, `islamic_names.json`,
`EXECUTION_LOG_SCHEMA.md`, `MASTER_PROMPT.md`'s worked example) was
rewritten onto the Zayd/Amira cast.

## Alternatives considered
1. **Keep both, treat as two separate series/shows.** Rejected — nothing
   in the original repository indicated this was intentional, and it
   would double the maintenance burden for no stated benefit.
2. **Retire Zayd/Amira, keep Nur/Lumi.** Rejected — the Zayd/Amira system
   has real, creator-provided turnaround reference images
   (`assets/characters/*.jpeg`) and an original source document
   (`Islamic_Kids_Studio_Character_Prompts.txt`) confirming it as the
   authored, human-originated design. The Nur/Lumi system had no
   equivalent visual reference — it appears to have been independently
   generated by an earlier pass of repository content and never
   reconciled against the real character art.
3. **Merge the two into a larger 10-character cast.** Rejected — this
   would create two protagonists-of-a-protagonist-pair situations and
   contradicts `DESIGN_PRINCIPLES.md`'s implicit small, focused-cast
   philosophy. Not what the creator asked for.

## Consequences
- All new episodes, prompts, and generated art must use only the six
  Zayd/Amira-cast characters and their locked description blocks.
- Any old episode records referencing Nur/Lumi (there are none currently
  published per `published_videos.json`) would need manual reconciliation
  if they existed — they do not, so this decision carries no retroactive
  content-migration cost.
- `phase2/data/language/islamic_names.json` kept the real name "Nur"
  (meaning "Light") as a general Islamic baby-name reference entry,
  unrelated to the retired character — this is a name-meaning fact, not
  a character reference, and stays.

## Source
`sources/characters/Islamic_Kids_Studio_Character_Prompts.txt` (original,
creator-provided), `assets/characters/*.jpeg` (creator-provided reference
art), audit simulation in repository review (2026-07-30).
