# ANIMATION STYLE TEMPLATE — Style Consistency Guide

## Style Requirements
- Character proportions: Rounded, big head (1:2.5 ratio), simple hands and feet.
- Line style: Soft, rounded, 2-3px equivalent.
- Color palette: Mint green, soft peach, warm cream, lavender, soft blue, pale yellow.
- Background: Soft watercolor-like gradients, gentle lighting.
- Movement: Gentle curves, no sudden jumps.
- Expressions: Large expressive eyes, gentle smiles, emotional range.
- Scale: Child-scale perspective.

## Consistency Rules
- Every scene must feel like it belongs to the same world.
- Every character must maintain consistent proportions and colors.
- Every background must use the same color palette.
- Lighting must feel warm and safe.
