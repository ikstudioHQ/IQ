# NARRATION TEMPLATE — Voice Script Template

## Sections
- Warm greeting (optional)
- Scene description (short, emotional)
- Action description (show, don't tell)
- Islamic value connection (gentle, earned)
- Closing (warm, with dua or song reference)

## Voice Requirements
- Voice: Warm, friendly, natural.
- Speed: Medium (child-appropriate pace).
- Pitch: High enough to feel friendly, not too high.
- Emotion: Genuine warmth.
- Pronunciation: Confirm Islamic terms using dictionary.
