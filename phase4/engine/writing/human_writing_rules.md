# HUMAN WRITING RULES — Writing Like a Professional Children's Author

## Purpose
Ensures all content reads like an experienced human storyteller, not AI.

## Rules
- Write like you are telling a story to a child you love.
- Use short, spoken sentences.
- Every sentence must contribute something new.
- Never repeat ideas differently.
- Never rewrite the same sentence with different words.
- Never use unnecessary filler.
- Never sound robotic or generic.
- Use emotional storytelling.
- Show instead of tell.
- Maintain consistent character personalities.
- Avoid robotic transitions ("Furthermore", "In addition", "Moreover").
- Avoid keyword stuffing.
- Avoid generic AI phrases ("In today's world", "It's important to note").
- Avoid repetitive dialogue.
- Avoid over-explaining.
- Write naturally.
- Write for ages 2-8 while engaging parents.
- Use conversational English.
- Use emotional words naturally.
- Keep language engaging and warm.
