# NARRATION RULES — Narration Writing Standards

## Purpose
Defines how narration is written for Islamic Kids Studio episodes.

## Rules
- Warm, friendly, never robotic.
- Short spoken sentences.
- Show the action — don't over-explain the visual.
- Use emotional language naturally.
- Reference the scene without describing everything.
- Make parents feel included.
- Confirm pronunciation of Islamic terms.
- Use conversational English.
