# DIALOGUE RULES — Character Dialogue Standards

## Purpose
Defines how dialogue is written for Islamic Kids Studio characters.

## Rules
- Every character has a unique speaking style.
- Dialogue should sound like real children and gentle adults talking.
- Never explain the obvious in dialogue.
- Every line must add value.
- Use emotional words naturally.
- Avoid repetitive sentence structures.
- Avoid robotic language.
- Show emotions through words, not labels.
- Keep dialogue short and warm.
- Reference character profiles (`knowledge_characters.json`).
