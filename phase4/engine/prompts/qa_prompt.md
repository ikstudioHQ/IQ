# QA PROMPT — Quality Assurance Validation

## Purpose
Validates generated content against all quality standards.

## Inputs
- Generated episode content (script, images, audio reference)
- Brand rules (`BRAND.md`)
- Writing rules (`RULES.md`)
- Islamic rules (`ISLAMIC.md`)
- Character rules (`CHARACTER.md`)
- Curriculum rules (`CURRICULUM.md`)

## Outputs
- Quality report (PASS/FAIL with details)
- Error log
- Improvement recommendations
- Final approval status

## Validation Checklist
Story Quality:
- [ ] Story teaches one clear value
- [ ] Conflict is gentle
- [ ] Resolution feels earned
- [ ] Character actions are consistent
- [ ] Writing is natural, not robotic
- [ ] No filler or repetition

Writing Quality:
- [ ] Every sentence adds value
- [ ] Conversational English used
- [ ] Short spoken sentences
- [ ] No robotic transitions
- [ ] No generic AI phrases

Islamic Quality:
- [ ] Islamic references are accurate
- [ ] No invented hadith or Quran citations
- [ ] No disputed opinions presented as facts
- [ ] Child-friendly explanations provided

Brand Quality:
- [ ] Brand colors and style maintained
- [ ] Character designs consistent
- [ ] Warm, safe, cute tone maintained
- [ ] Merchandise-friendly appearance

SEO Quality:
- [ ] Natural descriptions
- [ ] No keyword stuffing
- [ ] Clean metadata
- [ ] Brand references included
