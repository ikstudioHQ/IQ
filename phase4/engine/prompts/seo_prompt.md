# SEO PROMPT — SEO Content Generation

## Purpose
Generates SEO-optimized titles, descriptions, tags, and metadata.

## Inputs
- Episode title
- Topic
- Age group
- Brand (`BRAND.md`)
- Keywords (`keyword_database.csv`)

## Outputs
- SEO title
- Description (for parents)
- Tags
- Playlist recommendation
- Thumbnail text

## Rules
- Write naturally for parents.
- Mention main topics once, not repeated.
- Use clean metadata.
- Include channel branding: Islamic Kids Studio / @IslamicKidsHQ.
- Avoid misleading tags.
- Make descriptions warm and engaging.

## Template Structure
Title: [Clear, warm title including main keyword]
Description: [Natural paragraph for parents mentioning Islamic Kids Studio, the value taught, and invitation to subscribe. Include one mention of main keywords.]
Tags: [5-8 relevant tags from keyword database]
