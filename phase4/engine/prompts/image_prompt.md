# IMAGE PROMPT — Background & Object Generation

## Purpose
Generates prompts for backgrounds, props, objects, animals, and scenes.

## Inputs
- Scene description
- Environment ID (from `knowledge_world.json`)
- Character presence
- Lighting requirements
- Brand palette

## Outputs
- Detailed image prompt
- Style confirmation
- Composition notes
- Color reference

## Rules
- Always reference `BRAND.md` color palette.
- Always maintain soft, rounded shapes.
- Never include sharp edges or scary elements.
- Keep scenes at child-scale.
- Maintain warm lighting.
- Ensure characters are recognizable.

## Related Files
`WORLD.md`, `BRAND.md`, `CHARACTER.md`
