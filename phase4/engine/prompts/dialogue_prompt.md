# DIALOGUE PROMPT — Character Dialogue Module

## Purpose
Generates character dialogue for Islamic Kids Studio episodes.

## Inputs
- Character profiles
- Scene context
- Emotional state
- Previous dialogue (for continuity)

## Outputs
- Character dialogue lines
- Emotional direction (happy, sad, excited, calm)
- Pronunciation notes

## Rules
- Each character has a unique speaking style.
- Never use the same sentence structure repeatedly.
- Never explain the obvious.
- Show emotions through words and actions, not labels.
- Use conversational English only.
- Never sound like AI.
