# ANIMATION PROMPT — Animation Rules

## Purpose
Defines animation requirements for Islamic Kids Studio content.

## Inputs
- Scene description
- Character IDs
- Action requirements
- Duration

## Outputs
- Animation instructions
- Motion rules
- Timing notes
- Expression changes

## Rules
- Gentle movement — no sudden jumps.
- Soft, rounded motion curves.
- Consistent character proportions.
- Expressive facial animation.
- Easy lip-sync for dialogue.
- Warm lighting throughout.
- Child-scale perspective.
