- All v2.4 database files are backward compatible with v2.3/v2.0 structure.

- Repository-level generated/runtime metadata must match the Current Repository Version above; module/content artifact versions may remain independently versioned where documented.
- Future versions must not break v2.4 structure without a corresponding CHANGELOG entry.

- Character/asset/module versions (e.g. `Zayd v2.0`) are tracked independently of the repository version — see `phase1/docs/governance/versioning_policy.md`.
